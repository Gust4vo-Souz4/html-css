Lista de Definições

HTML
Linguagem de marcação para a criação do conteúdo de um site.
CSS
Linguagem de marcação para a criação do design de um site.
JavaScript
Linguagem de programação para adicionar interatividade a um site.
Python
Linguagem de programação de alto nível, muito utilizada em ciência de dados e desenvolvimento web.
Java
Linguagem de programação orientada a objetos, amplamente utilizada em aplicações corporativas e desenvolvimento Android.
C#
Linguagem de programação desenvolvida pela Microsoft, usada principalmente para desenvolvimento de aplicativos Windows e jogos com Unity.
Fortran
Linguagem de programação de alto nível, uma das mais antigas, usada principalmente em cálculos científicos e engenharia.
Delphi
Ambiente de desenvolvimento integrado (IDE) e linguagem de programação baseada em Pascal, usada para desenvolvimento de aplicativos desktop.
Visual Basic
Linguagem de programação desenvolvida pela Microsoft, usada para desenvolvimento de aplicativos Windows com uma interface gráfica.
